Точки притяжения Иркутска для посуточной аренды

Sweet Home · данные Яндекс Вордстата, ноябрь 2026 · показы в месяц

Как отбирали. Место считается точкой притяжения, если его ищут люди, которым нужно приехать в Иркутск и переночевать. Три сигнала из Вордстата:
  • Жильё рядом — запросы «квартира / гостиница / посуточно / хостел / общежитие» вместе с названием места;
  • Приезжие — доля запросов о месте не из Иркутска (разбивка Вордстата по городам);
  • Поездка — «как добраться», «запись», «поступление».

Не вошли

  • БГУ — 22% приезжих, но запросов про жильё почти нет (8).

Ограничения. Полная проверка по трём сигналам выполнена для 5 мест (аэропорт, ИРНИТУ, ИрГУПС, диагностический центр, БГУ) — дальше закончился лимит запросов к Вордстату. Для остальных использованы запросы «рядом / возле» и общий объём поиска. Места 11–13 добавлены по смыслу и требуют проверки.
